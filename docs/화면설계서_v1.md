## 1. 공통 레이아웃 (모든 화면 공유)

화면은 상단 크롬 → 모드별 콘텐츠 영역 → 하단 에뮬레이터 바의 3단 구조임.

```
┌──────────────────────────────────────────────────────────────┐
│ [GNB]  H2 로고·디지털트윈 | 6개 모드탭 | 실행중 | 알람 | 설정 | 보고서   │  h48
├──────────────────────────────────────────────────────────────┤
│ [API 상태바] 외부기관 · KOGAS · KGS · KETI · 세이프티아 (연결상태)      │  h28
├──────────────────────────────────────────────────────────────┤
│                       [모드별 콘텐츠 영역]                          │
├──────────────────────────────────────────────────────────────┤
│ [에뮬레이터 바] 시나리오 | 배속 1/10/30/60x | 제어 | 페이즈 진행바 | 시간 │  h44
└──────────────────────────────────────────────────────────────┘
```

| 구성요소 | 컴포넌트 | 사양 |
|---------|---------|------|
| GNB | `components/layout/GNB.tsx` | 로고, 6개 운영모드 탭, 시나리오 실행상태, 알람 카운트, 설정/보고서 진입 |
| API 상태바 | `components/layout/ApiStatusBar.tsx` | 4개 외부기관 health(🟢정상/🟡지연/🔴실패/⚪미사용) 30초 주기 polling |
| 에뮬레이터 바 | `components/layout/EmulatorBar.tsx` | 시나리오 선택, 배속, ▶시작/⏸일시정지/⏹중지, 5단계 페이즈 진행바, 경과/총시간 |

- 페이즈: NORMAL(정상) → SYMPTOM(이상감지) → FAULT(고장) → SECONDARY_IMPACT(시뮬레이션) → RESPONSE(대응/복구)
- 색상 테마(다크): 배경 `#0a0e17`, 크롬 `#0c1220`, 포인트 시안 `#22d3ee`
- 상태 컬러: 정상 `#10b981` / 경고 `#f59e0b` / 위험 `#ef4444` / 영향 `#fbbf24` / 시뮬대상 `#c084fc`

## 3. 화면별 상세

### 3.1 M-MON · 전주기 운전 모니터링

- **목적**: 3D/2D 공간 보기로 설비 상태·센서값·알람을 상시 확인하는 기본 화면.
- **레이아웃**: 좌(공정흐름 패널 210px) · 중앙(3D 뷰어) · 우(설비정보 패널 260px) 3분할.
- **주요 컴포넌트**
  - 좌측 `ProcessFlowNavigator`: 4단계 공정(하역 → 저장·BOG → 이송 → 기화·송출), 설비별 상태 뱃지, 이벤트 발생 시 해당 공정 박스 강조(주황/적색), 벤트스택 비상 경로.
  - 중앙 3D 뷰어(`ThreeCanvas` + `TestbedModel`): h2.glb 테스트베드, 설비 클릭 시 카메라 이동·컬러링. 좌상단 핵심설비 KPI 오버레이(정상/경고/이상 카운트 + 설비 칩).
  - 우측 `EquipmentInfoPanel`: 선택 설비 제원, 센서 현재값(운전범위 게이지), 알람 이력.
  - 이벤트 팝업(드래그 가능): CRITICAL 배지, 시나리오/단계/영향설비, KOGAS·KGS·이력·SOP 요약, 모드 전환 버튼.
- **상호작용**: 설비 아이콘/KPI 카드 클릭 → 3D 카메라 이동 + 우측 패널 갱신. 이벤트 팝업의 모드 버튼 → 해당 모드로 컨텍스트 유지 전환.

### 3.2 M-ANO · 설비 상태감시 / 이상탐지

- **목적**: KOGAS 이상탐지 AI 결과를 설비 단위로 표출.
- **레이아웃**: 상단 3분할(좌 센서차트 22% · 중앙 3D 설비 뷰 · 우 센서차트 22%) + 설비선택 탭 + 하단 3분할(이상탐지 그래프 · 시간별 상세 테이블 · 진단 데이터) + KOGAS 진단 결과 바.
- **주요 컴포넌트**
  - 중앙 3D: PMP-301 선택 시 `secondary_pump.glb` X-ray 모드(임펠러 3·4단 적색, 축 주황), 그 외 설비는 격리 뷰. 하단 펌프/모터 부하 인디케이터.
  - 좌/우 센서 차트(`SensorChart`): 임계선 표시, 이상 구간 적색 배경.
  - 하단 `AnomalyDetectionChart`: 실측값(시안) vs 학습값(보라) + 오차, 이상 구간 강조.
  - KOGAS 진단 결과 바: 연결상태 + 고장명 + 확신도 + 의심부위 + 모드전환 버튼.
- **연동**: 이벤트 발생 시 자동으로 센서값을 KOGAS API로 전송 → 자동 진단(사용자 입력 불필요).

### 3.3 M-RSK · 상호영향 위험예측

- **목적**: KGS 상호영향 위험예측을 2D 네트워크 + 3D 컬러링 + HAZOP 텍스트로 통합 표출.
- **레이아웃**: 상단 분석 입력 바 + 3분할(좌 2D 영향 네트워크 30% · 중앙 3D 영향 컬러링/히트맵 40% · 우 HAZOP+상세 30%).
- **주요 컴포넌트**
  - 분석 입력 바: 이벤트 연계(자동채움) 또는 수동 선택(설비/분석시간/KGS 파라미터), 🟢KGS 연결정상, [▶ 위험예측 실행] [↻ 초기화].
  - 좌측 `ImpactNetwork2D`(react-flow): trigger(BOG-201) → affected(TK-101 88점, REL-701 64점) 노드-엣지, 구역(zone) 영향도 바, 시간축 예측 카드(0/10/30/60분).
  - 중앙 3D: trigger 적색 + affected 황색 컬러링, 위험 반경 히트맵 오버레이, 영향 전파 점선 애니메이션, 하단 시간축 슬라이더.
  - 우측 `HazopPanel`: 원인/이벤트/위험/예방/비상, 권고 조치, 연계 SOP([SOP 팝업실행][SOP 전체화면]).
- **연동**: 이벤트 연계 시 센서값+설비정보 자동 전송, 수동 실행 시 입력 패널 파라미터 사용.

### 3.4 M-SIM · 시뮬레이션 / 의사결정지원

- **목적**: KETI 시뮬레이션 결과로 대응안을 비교·결정.
- **레이아웃**: 탭(이벤트 연계 실행 / 수동 실행) + 입력·제어 패널 + 2분할(좌 3D 시뮬레이션 뷰어 50% · 우 결과 패널 50%).
- **주요 컴포넌트**
  - 입력·제어: 시나리오/트리거 설비/이상유형, 파라미터 슬라이더(초기압력·지속시간·온도편차·유량변화), 🟢KETI 연결정상, [▶ 실행][⏸][⏹][↻], 진행률.
  - 좌측 3D: 타임라인 스크러버로 시점 탐색, trigger 점멸 + affected 점진 변화 + 영향반경/가스 확산.
  - 우측: KGS 위험영향 결과(설비별 점수·전파시각), KETI 대응안 비교(A 재액화기 가동 18분/중, B 벤트 후 정비 25분/저, [적용▶]), KETI 시뮬레이션 요약.
- **독립 실행**: 이벤트 없이도 시나리오/파라미터 직접 입력 후 실행 가능.

### 3.5 M-HIS · 이력조회 / 분석

- **목적**: 세이프티아 이력 및 설비 점검/사고/정비 이력 조회.
- **레이아웃**: 좌(필터: 설비/기간/유형) · 우(이력 목록 테이블 + 이력 상세).
- **주요 컴포넌트**
  - 좌측 필터: 설비 체크리스트, 기간(최근 1개월/3개월/1년/전체), 유형(정비/점검/교체/사고).
  - 이력 목록: 구분·일자·내용·설비·상태 테이블, 행 선택 강조.
  - 이력 상세: 점검일/내용/연계SOP/운영자메모, [위험예측] [관련 이벤트 보기].

### 3.6 M-SOP · 디지털 SOP

- **목적**: SOP 실행(메인) + 저작/편집/버전관리(부가).
- **레이아웃**: 탭(실행 / 저작·편집 / 실행이력) + 좌(SOP 목록 9종) · 우(SOP 실행 패널).
- **주요 컴포넌트**
  - SOP 목록: 카테고리(EMERGENCY/SAFETY/ROUTINE) 색상 구분, 추천 SOP 선택 강조.
  - 실행 패널(`SopExecutionPanel`): 헤더(SOP ID·대상·예상소요), 진행률, 체크리스트(완료/미완료), 메모, [실행완료] [상황전파].
  - 듀얼 UI: 운영모드 이벤트 팝업의 [SOP 팝업실행]은 축소(`compact`), [SOP 전체화면]은 본 화면으로 전환.

### 3.7 P-SET · 설정

- **목적**: 센서 메타데이터·설비 임계치·운영정책 관리.
- **레이아웃**: 탭(센서 메타데이터 / 임계치 관리 / 운영정책).
- **주요 컴포넌트**
  - 센서 메타데이터: ID·이름·유형·설비·단위·주기(s)·활성 테이블(인라인 편집), [저장].
  - 임계치 관리: 설비 선택 → 센서별 경고 하/상한·위험 하/상한 편집, [기본값 복원] [저장].
  - 운영정책: SOP 자동팝업/자동 보고서 초안 토글, Missing Data Timeout·기본 샘플링 주기, 3D 이펙트 ON/OFF.

### 3.8 P-RPT · 보고서

- **목적**: 이벤트 조치 보고서 자동생성·편집·상태관리.
- **레이아웃**: 좌(보고서 목록) · 우(보고서 상세).
- **주요 컴포넌트**
  - 보고서 목록: RPT-SC-* 목록, 상태(DRAFT/SUBMITTED), [+ 이벤트 기반 보고서 생성].
  - 보고서 상세: 자동수집 데이터(이벤트 개요/트리거 설비/KOGAS 진단/KGS 영향분석/KETI 권고안/이력 요약/SOP 수행이력) + 관리자 작성(관리자 의견/후속조치) + 상태관리 + [저장][제출][PDF].
- **자동생성**: 이벤트 CLOSED 시 각 외부기관 mock 결과 + SOP 수행이력을 조합하여 DRAFT 생성.

## 4. 외부기관 연동 요약

| 기관 | 역할 | 표출 화면 | 데이터 전송 |
|------|------|----------|-----------|
| KOGAS | 이상탐지/고장인지 | M-ANO | 이벤트 발생 시 자동 |
| KGS | 상호영향 위험예측 | M-RSK, M-SIM | 이벤트 연계 자동 / 수동 입력 |
| KETI | 시뮬레이션 | M-SIM | 이벤트 연계 자동 / 수동 입력 |
| 세이프티아 | 사고대응/이력관리 | M-HIS | 이벤트 종료 시 자동 기록 |
